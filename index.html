    English Loop 사용 안내

    1. 여섯 문장, 붙여 넣고 바로 듣기

    복사한 문장 붙여넣기 → 학습 시작만 누르세요. 별도 ‘문장 적용’은 필요 없습니다. 기본값은 0.9배속 · 문장마다 3회 · 매번 5초 쉼입니다. 처음에는 입력칸이 비어 있으며 ‘예문 6개’로 시험할 수 있어요.

    버튼이 작동하지 않거나 권한을 거절했다면 입력칸을 길게 눌러 붙여넣기를 선택하세요. 붙여넣기 버튼은 현재 입력을 교체하며, ‘되돌리기’로 교체 직전 내용을 복원할 수 있습니다. 텍스트를 자동으로 읽어 오지 않고 버튼을 눌렀을 때만 클립보드에 접근합니다.

    1. Could you say that again?
2. Let me think about it.
3. Let's keep in touch.

    영어는 한 줄에 한 문장씩 넣으세요. 6문장은 권장 분량이며 개수 제한이 아닙니다. 더 많아도 자르지 않습니다. 제목·입력 옵션에서 긴 문단 나누기를 켤 수 있어요. 한 번에 최대 200개, 한 단위 최대 2,000자입니다.

    한국어 뜻은 영어 다음 줄이나 | 뒤에 넣으면 화면에 표시하고 영어만 읽습니다. 자동 번역은 하지 않습니다. 번호·글머리표와 명시적인 마크다운 제목은 제외하지만 일반 영어 제목·설명은 문장으로 들어갈 수 있으니 문장 수를 확인하세요.

    2. 모바일에서 듣기

    재생을 시작하면 입력칸은 접히고 현재 문장이 크게 나옵니다. 화면 아래에서 이전 · 재생/일시정지 · 다음 · 정지를 언제든 누를 수 있어요. ‘문장 입력 ↑’로 입력칸을 다시 열 수 있습니다. 목소리·속도·반복 설정은 ‘재생 설정’을 펼쳐 바꾸세요.

    읽다가 일시정지하면 이어 듣기 시 해당 문장을 처음부터 읽고, 쉼 도중 일시정지하면 남은 쉼부터 이어갑니다. 재생을 완료한 뒤 ‘한 번 더 학습’으로 전체를 다시 들을 수 있습니다. 재생 위치는 페이지를 완전히 다시 열면 복원되지 않습니다.

    화면을 잠그거나 다른 앱으로 전환하면 일시정지합니다. ‘재생 중 화면 켜두기’는 지원 기기·HTTPS 환경에서만 시도하며, 절전 설정 등에 따라 실패할 수 있어요. 이 버전은 MP3 저장이나 백그라운드 재생을 제공하지 않습니다.

    3. 목소리가 없거나 소리가 안 나올 때

    GitHub Pages의 웹 주소를 휴대폰의 Safari 또는 Chrome에서 직접 여세요. 파일 미리보기 안에서는 기능이 제한될 수 있어요. 음량·이어폰 연결을 확인하고 재생 설정의 목소리 새로고침 → 미리 듣기를 눌러보세요.

    ‘기기 내 음성만 사용’은 브라우저가 localService=true로 보고한 영어 음성만 허용합니다. 없을 때 연결형 음성으로 자동 전환하지 않습니다. 기기에 영어 음성을 설치하거나 해당 옵션을 직접 해제해 연결형 음성을 사용하세요.

    4. 보관과 개인정보

    입력과 설정은 같은 브라우저에 자동 저장됩니다. ‘학습할 문장’을 펼친 뒤 보관함에 저장하면 과거 세트를 남길 수 있어요. 최대 30세트를 보관하며, 보관함에서 JSON 백업 저장·불러오기를 사용할 수 있습니다.

    기기 간 자동 동기화, 날짜별 복습, 발음 채점, 오프라인 앱 캐시는 포함하지 않았습니다. 브라우저 데이터를 지우거나 비공개 모드를 사용하면 저장이 유지되지 않을 수 있습니다. 같은 기기에서도 브라우저·홈 화면 실행 방식에 따라 저장 공간이 다를 수 있으니 중요한 문장은 백업하세요.

    이 웹에는 유료 API, 로그인, 광고, 분석 도구나 문장을 별도 앱 서버로 전송하는 코드가 없습니다. 연결형 목소리는 브라우저·운영체제의 음성 서비스로 텍스트를 보낼 수 있습니다. 민감한 문장은 기기 내 음성을 사용하세요. 클립보드는 붙여넣기 버튼을 눌렀을 때만 읽습니다.

    GitHub에 올릴 때는 실행 파일만 올리고 개인 문장이 들어 있는 백업 JSON은 공개 저장소에 올리지 마세요.
