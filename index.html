    학습과 준비를 나누었어요
    학습에는 현재 문장·재생·별표·문장 목록만, 문장·설정에는 붙여넣기·음성 생성·재생 설정이 있습니다. 목소리 준비는 문장·설정 아래에서 필요할 때만 펼치세요. 매번 테스트할 필요는 없습니다.
    새 문장을 모두 준비하면 학습 탭으로 이동합니다. 실제 재생은 학습 시작을 직접 눌러 시작합니다. 저장된 첫 문장 음성을 불러온 경우 다음 방문에는 학습 화면으로 열립니다. 페이지를 완전히 다시 열었을 때 지난 재생 위치까지 복원하는 기능은 아닙니다.
    탭만 바꾸어도 음성 생성은 계속됩니다. 문장·설정으로 이동하면 학습 소리만 일시정지하며, 같은 페이지에서 돌아와 이어 들을 수 있습니다. 학습 중 생성 상태는 작은 상태 표시로 보이고 ‘상세’에서 전체 기록을 확인할 수 있습니다.
    GPU로 한 문장부터 확인하세요
    GPU로 한 문장 시험은 GPU 확인 후 모델을 준비하고 짧은 예문을 새로 만듭니다. 이 시험은 저장된 음성을 재생하는 것이 아니라 매번 실제 생성을 측정합니다. GPU만 확인 버튼은 모델을 다운로드하지 않습니다. GPU 검사 통과가 Kokoro 실행 성공을 보장하지는 않습니다. 완료되면 나타나는 오디오의 ▶를 눌러 들어보세요. 사전 녹음 샘플이 아니라 이 기기에서 직접 생성한 결과입니다.
    

    매일의 여섯 문장
    문장 붙여넣기 → 문장 음성 만들기 → 학습 시작. 기본값은 1.0배속 · 3회 반복 · 매번 5초 쉼입니다. 6문장은 권장량이며, 시험판은 한 번에 최대 24문장, 한 줄 600자, 총 입력 12,000자를 허용합니다. 제한을 넘으면 안내하고, 내용을 잘라 버리지 않습니다.
    영어는 한 줄에 한 문장. 한국어 뜻은 다음 줄 또는  |  뒤에 넣으면 화면에만 표시합니다. 번호·글머리표·명시적 마크다운 제목은 제외합니다. 일반 영어 제목은 문장으로 인식될 수 있으니 목록을 확인하세요. 자동 번역이나 발음 채점은 하지 않습니다.
    긴 한 줄은 생성할 때 짧은 구간으로 나눈 뒤 이어 붙입니다. 새 문장의 전체 생성 대기는 최대 60초로 제한하며, 이 값은 오류 판정이 아닌 앱의 대기 상한입니다. 파일 다운로드·모델 초기화 시간은 별도입니다. 아주 긴 문장은 구간 사이의 억양이 달라질 수 있어요. 입력을 고치면 바뀐 문장만 다시 만들고, 같은 내용의 저장된 소리는 재사용합니다.
    

    아이폰 사용과 중지
    파일 미리보기가 아니라 GitHub Pages의 HTTPS 주소를 Safari에서 여세요. 음성 생성 중에는 화면을 열어두고, 처음에는 다른 탭을 줄이고 Wi-Fi에서 사용하세요. 첫 문장 음성이 완성되면 아래 재생 버튼으로 먼저 들을 수 있습니다. 같은 페이지에서 나머지 문장을 순서대로 생성합니다. 다음 문장이 아직 없으면 대기하고, 생성이 중지됐다면 이어 듣기는 준비된 문장에 한해 가능합니다. 화면 잠금·앱 전환 시 학습은 일시정지하고, 진행 중인 음성 생성은 중지합니다. 다시 눌러 완료된 소리는 재사용할 수 있어요.
    읽다가 일시정지하면 이어 듣기 시 해당 문장의 처음부터 읽습니다. 쉼 도중에는 남은 쉼부터 이어갑니다. 이전·다음으로 건너뛴 문장은 완료로 세지 않습니다. 재생 위치는 페이지를 완전히 닫으면 복원되지 않습니다. 화면 켜두기는 지원되는 환경에서만 시도합니다.
    페이지가 갑자기 새로고침된다면 메모리 부족 또는 브라우저 제약일 수 있습니다. 자동으로 모델을 다시 실행하지 않습니다. 다른 탭을 닫고 한 문장만 시도해보세요. 계속 반복되면 이 기기에서는 시험을 멈추고 기존 단축어를 사용하세요.
    소리가 안 들리면 볼륨과 이어폰 연결, 무음 설정을 확인하고 재생을 직접 누르세요. 이 버전에는 백그라운드 재생 보장이나 MP3 내보내기는 없습니다.
    

    파일 다운로드·요금·개인정보
    사용한 모델은 Kokoro 82M v1.0 · fp32 · WebGPU, 목소리는 am_puck입니다. 모델 본체 약 326MB에 목소리·라이브러리·실행 파일 다운로드가 추가됩니다. 다운로드 전 웹을 여는 것만으로는 모델을 받지 않습니다. 유료 TTS API, 로그인, API 키, 광고, 분석 도구를 사용하지 않습니다. 인터넷 데이터 요금은 통신 요금제에 따릅니다.
    실행 파일은 jsDelivr, 모델·목소리는 Hugging Face에서 받습니다. 이 서비스에는 파일 다운로드 접속 정보가 전달됩니다. 학습 문장은 음성 생성 서버에 보내지 않고 이 기기에서 처리합니다. 학습 문장을 담은 공개 링크도 만들지 않습니다. 외부 파일을 못 받는 환경에서는 새 음성 생성이 실패할 수 있습니다.
    GPU 모델은 이전 q8 모델과 다른 파일이라 별도 다운로드가 필요합니다. GPU 미지원이나 모델 실행 실패 시 CPU로 조용히 전환하거나 자동 재시도하지 않습니다. 모델 준비 전체 상한은 4분, 파일 진행이 멈추거나 초기화가 끝나지 않을 때도 단계별 대기 상한을 적용합니다. 모델은 라이브러리의 브라우저 캐시, 완성된 문장 음성은 별도 로컬 저장 공간에 재사용을 시도합니다. 브라우저가 저장 공간을 지우면 다시 받거나 만들어야 합니다. 완전한 오프라인 앱은 아닙니다. 다시 열 때 실행 파일 등을 온라인으로 불러올 수 있어요.
    

    이전 버전과 보관함
    같은 주소·브라우저의 이전 English Loop 문장과 보관함을 새 저장 공간으로 복사해 가져옵니다. 이전 버전의 원본 저장 공간은 수정·삭제하지 않습니다. 이전 음성 선택은 가져오지 않으며 Puck을 사용합니다. 새 버전의 보관함은 최대 60세트입니다. 기존의 너무 긴 학습 세트는 불러와도 생성 제한에 따라 나누어야 합니다.
    문장·설정·보관함 백업은 JSON 파일입니다. 생성 음성·모델·재생 위치는 백업에 포함되지 않습니다. PC와 휴대폰은 자동 동기화하지 않습니다. 개인 백업 JSON 파일을 GitHub 공개 저장소에 올리지 마세요.
    

    홈 화면에 추가하기
    배포된 웹을 Safari에서 열고 공유 → 홈 화면에 추가 → 추가를 선택하세요. ‘웹 앱으로 열기’가 표시되면 켜세요. 앱 이름은 English Loop입니다. 아이콘은 사용자가 제공한 파랑·보라 마이크 로고입니다. 웹 상단 로고와 탭 아이콘은 HTML 안에 포함되어 있습니다.
    홈 화면 아이콘까지 바꾸려면 ZIP을 해제한 뒤 index.html과 아이콘 PNG, manifest.webmanifest를 같은 위치에 올려주세요. index.html만 올려도 웹 안의 로고와 탭 아이콘은 바뀌지만, 홈 화면 아이콘에는 별도 PNG 파일이 필요합니다. 기존 홈 아이콘을 교체하기 전에는 보관함에서 문장을 먼저 백업하세요. 홈 화면 추가는 완전한 오프라인 사용이나 백그라운드 음성 생성을 보장하지 않습니다.
