# English Loop — 모바일 · 여섯 문장

복사한 영어 문장을 넣고 기기 음성으로 반복해서 듣는 개인 학습 웹입니다. 유료 API나 별도 음성 서버가 필요하지 않습니다.

## 사용

1. 휴대폰에서 연습할 영어 문장을 복사합니다.
2. 배포한 웹을 열고 **복사한 문장 붙여넣기**를 누릅니다.
3. 표시되는 문장 수를 확인한 뒤 **학습 시작**을 누릅니다.

붙여넣기 버튼이 작동하지 않거나 권한을 거절했다면 입력칸을 길게 눌러 기본 붙여넣기를 사용하세요. PC에서는 Ctrl+V로 넣어도 됩니다. 버튼은 현재 입력을 교체하며 ‘되돌리기’로 교체 직전 입력을 복구할 수 있습니다.

6문장은 기본 사용 분량이지 제한이 아닙니다. 7개·10개를 넣어도 자르지 않습니다. 초기 화면은 비어 있고 ‘예문 6개’ 버튼을 누르면 예문으로 시험할 수 있습니다.

## 기본 설정

- 0.9배속, 각 문장 3회 반복, 각 듣기 뒤 5초 쉼
- 기기 내 영어 음성만 사용
- 지원 환경에서 재생 중 화면 켜두기 시도

재생을 시작하면 입력칸이 접히고 현재 문장 화면으로 이동합니다. 화면 아래에서 재생·일시정지·이전·다음·정지를 조작할 수 있습니다. ‘문장 입력 ↑’를 누르면 입력칸이 열립니다. 입력칸의 ‘학습 시작’은 입력한 전체 문장을, 화면 아래 재생 버튼은 학습 목록에서 선택한 문장을 재생합니다.

‘재생 설정’을 펼치면 속도·반복·쉼·음성을 바꿀 수 있습니다. 기기 내 영어 목소리가 없으면 해당 패널이 자동으로 열립니다. 음성을 설치하거나 ‘기기 내 음성만 사용’을 직접 해제할 수 있습니다. 연결형 음성으로 자동 전환하지 않습니다.

## GitHub Pages에 새로 올리기

새 저장소를 사용하면 기존 Landscape 웹과 분리할 수 있습니다.

1. GitHub에서 새 공개 저장소를 만듭니다. 이름 예: `english-loop`.
2. ZIP을 해제합니다. `index.html`, `.nojekyll`, `README.md`를 저장소 최상위에 업로드합니다. ZIP 자체가 아니라 해제한 파일을 올립니다.
3. 저장소의 Settings → Pages → Build and deployment에서 Deploy from a branch를 선택합니다.
4. main 브랜치, /(root)를 지정한 뒤 Save를 누릅니다.
5. 배포가 완료되면 Pages에 표시되는 웹 주소를 휴대폰에서 엽니다.

이 패키지는 아직 사용자의 GitHub에 업로드하거나 실제 배포하지 않았습니다.

## 이미 올린 버전 교체

기존 저장소 최상위의 `index.html`을 이 ZIP의 `index.html`로 교체하고 커밋합니다. 두 파일을 다른 이름으로 함께 올릴 필요는 없습니다. 같은 사이트·같은 브라우저의 기존 입력과 보관함은 이전 버전과 같은 저장 키·데이터 형식으로 읽습니다. 중요한 기록은 교체 전에 앱 보관함에서 백업하세요. 로컬 파일에서 새 웹 주소로 옮기거나 브라우저를 바꾸는 경우 자동 이전되지 않으므로 JSON 백업 불러오기를 사용하세요.

개인 문장이 들어 있는 백업 JSON 파일은 공개 저장소에 올리지 마세요.

## 입력 형식

영어를 한 줄에 한 문장씩 넣는 방식이 가장 단순합니다.

```text
1. Could you tell me more about your team?
2. What problem are you trying to solve?
3. Who are your main customers?
4. Could you say that again?
5. Let me think about it.
6. Let's keep in touch.
```

한국어 뜻은 다음 줄 또는 ` | ` 뒤에 넣을 수 있습니다. 뜻은 화면에만 표시하고 영어만 읽습니다. 일반 영어 설명이나 제목까지 함께 복사하면 학습 문장으로 들어갈 수 있으니 문장 수를 확인하세요. 줄바꿈이 없는 긴 문단은 제목·입력 옵션에서 나누기를 켜세요.

## 보관과 한계

입력·설정은 해당 브라우저에 자동 저장됩니다. ‘학습할 문장’을 펼치면 별표 선택·보관함 저장이 나옵니다. 보관함은 30세트까지 지원합니다. 백업은 JSON 형식이며 음성 파일이 아닙니다.

이 버전은 MP3 생성, 날짜별 복습, 발음 채점, 기기 간 자동 동기화, 별도 오프라인 앱 캐시를 포함하지 않습니다. 재생 위치는 새로고침/완전 종료 후 복원하지 않습니다.

화면 잠금·앱 전환 시 일시정지합니다. 홈 화면에 추가해도 백그라운드 음성 재생이 보장되지 않습니다. 실제 제공되는 음성은 기기·브라우저에 따라 다릅니다.

## 개인정보

별도 앱 서버로 문장을 전송하는 코드, 외부 분석 도구, 로그인, 광고, 유료 API가 없습니다. 클립보드는 버튼을 눌렀을 때만 읽습니다. 연결형 음성은 브라우저·운영체제의 음성 서비스로 텍스트를 전송할 수 있으므로 민감한 문장은 기기 내 음성을 사용하세요. 브라우저의 로컬 저장 공간은 같은 기기를 쓰는 다른 사람에 대한 암호화 보관소가 아닙니다.
