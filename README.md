## 두 탭의 역할

‘학습’: 현재 문장, 반복 재생, 진행률, 별표, 문장 목록, 영어 가리기.
‘문장·설정’: 영어 붙여넣기, 음성 만들기, 속도·반복·쉼, 선택적인 목소리 테스트.
목소리 준비는 맨 아래에 접혀 있습니다. 매번 테스트할 필요가 없습니다.

저장된 첫 번째 선택 문장 음성이 있으면 다음 방문에 학습 탭으로 엽니다.
없으면 문장·설정 탭으로 엽니다. 모델과 음성을 자동으로 새로 생성하지 않습니다.
음성 생성이 모두 끝나면 학습 탭으로 이동하고, 실제 소리는 사용자가 재생을 눌러 시작합니다.
생성 중 사용자가 다른 탭이나 설정으로 이동하면 완료 시 화면을 강제로 바꾸지 않습니다.
첫 문장만 준비돼도 ‘먼저 듣기’로 학습을 시작할 수 있습니다.

문장·설정 탭으로 이동하면 학습 소리만 일시정지합니다.
탭 이동으로 음성 생성 작업이 중단되지는 않습니다. 같은 페이지에서 이어 들을 수 있습니다.
페이지를 완전히 닫은 뒤 지난 재생 위치까지 복원하는 기능을 추가한 것은 아닙니다.
화면 잠금·다른 앱으로 전환 시 생성은 중지하고 학습 소리는 일시정지하는 기존 동작을 유지합니다.

## 모델·저장·개인정보

기존 데이터 형식, 로컬 저장 키, 문장 음성 캐시 키를 유지합니다.
기존 음성은 읽을 수 있는 저장소에 남아 있을 때 재사용합니다.
브라우저가 사이트 데이터를 정리했거나 다른 주소·브라우저이면 보장되지 않습니다.
모델: Kokoro 82M v1.0 / fp32 / WebGPU. 목소리: am_puck.
Kokoro를 실행하는 작업 스레드 코드는 v2.3과 동일합니다.
유료 API, 로그인, 분석 도구를 추가하지 않았습니다.

## 확인 범위

모바일 크기의 두 화면과 탭 전환, 음성 생성 중 이동·중지, 일시정지·이어 듣기,
자동 화면 전환, 캐시가 있는 시작 흐름, 오류 표시, 키보드 탭 이동을
모의 음성·모의 저장소를 사용하는 브라우저 테스트로 점검했습니다.
320~1100px 폭에서 두 화면의 가로 넘침도 확인했습니다.
실제 Kokoro 모델 추론과 iPhone 16 Pro/Safari에서의 성능·저장 유지·홈 아이콘 설치는
이 환경에서 검증하지 않았습니다. GPU 실행 기능은 계속 시험판입니다.

접근성 탭 동작 참고: https://www.w3.org/WAI/ARIA/apg/patterns/tabs/
기존 모델·라이브러리의 출처와 라이선스는 웹 안의 ‘사용 안내’에 있습니다.
